# RAG Pipeline from Scratch

A complete Retrieval Augmented Generation (RAG) pipeline 
built using LangChain, FAISS, and HuggingFace transformers.

## What it does
- Loads and chunks documents intelligently
- Converts text to vector embeddings using HuggingFace
- Stores vectors in FAISS vector database
- Retrieves semantically relevant context
- Generates answers using DistilBERT QA model

## Tech Stack
- LangChain — document loading and chunking
- HuggingFace Transformers — embeddings and LLM
- FAISS — vector similarity search
- Python — core implementation

## How to Run
1. Open in Google Colab
2. Run cells sequentially
3. Ask your own questions!
